# Machine Learning Projects

This repository contains three projects completed for the university course Machine Learning and Data Mining:

- **Homework 1: Clustering and Association Rule Analysis**
  - Clustered data from the BIRCH3 dataset using several clustering approaches; HDBSCAN with 72 clusters achieved the best results.
  - Performed association rule analysis to uncover relationships between supermarket products.

- **Homework 2: Causality**
  - Applied the Peter-Clark (PC) algorithm to investigate potential causal relationships between medical variables and coronary heart disease.

- **Final Project: Traffic Forecasting**
  - Forecasted traffic volume 15 minutes ahead using historical traffic patterns and spatio-temporal features from 36 sensor locations in the Northern Virginia/Washington, D.C. region.
  - Experimented with several architectures, including GCNs, GRUs, 1D CNNs, Transformers, and MLPs. Surprisingly, a simple MLP with sensor embeddings achieved performance comparable to the best-performing Transformer and CNN-GCN models.
